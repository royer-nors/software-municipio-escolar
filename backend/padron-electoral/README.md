# Módulo de Padrón Electoral

## Sistema de Votación del Municipio Escolar

Este módulo permitirá administrar el padrón electoral
de los estudiantes que participarán en las elecciones.

## Funcionalidades

1. Importar estudiantes desde un archivo Excel.
2. Registrar estudiantes habilitados para votar.
3. Consultar el padrón electoral.
4. Verificar si un estudiante está habilitado.
5. Evitar que un estudiante vote más de una vez.

## Tecnologías del proyecto

- Backend: Node.js y Express.
- Base de datos: PostgreSQL.
- Control de versiones: Git y GitHub.

Desarrollo del módulo de padrón electoral.
